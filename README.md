# Survey-Feedback-Analyzer
Python-Fundamentals-Module End Assignment
Project Overview

The Survey Feedback Analyzer is a Python-based project developed as part of the Python Fundamentals Module End Assignment. It processes customer feedback, cleans text data, analyses keywords, and generates summary statistics based on feedback ratings.

Objectives

Collect and store survey feedback.

Add new feedback entries dynamically.

Clean feedback text by removing punctuation, extra spaces, and converting text to lowercase.

Count feedback entries containing specific keywords.

Calculate the average rating.

Identify the feedback with the longest comment.

Extract unique words from all feedback entries.

Sort feedback entries based on ratings.
